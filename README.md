# icm_bompastor

Gerador de escala **Oração Ininterrupta** — Igreja Cristã Maranata.

## Como usar

1. Execute `iniciar.bat` (requer [Node.js](https://nodejs.org/)).
2. Abra o endereço exibido no terminal (ex.: `http://localhost:8080`).
3. No celular, use o IP da rede local na mesma Wi‑Fi.

## Arquivos principais

- `index.html` — criar e listar escalas
- `escala.html` — inscrição nos horários
- `server.js` — servidor local para compartilhar na rede
